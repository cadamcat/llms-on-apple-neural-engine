# LLMs on Apple Neural Engine 研究文章

[English](../README.md) | 中文

本系列把可复现实验整理成连贯的技术分析。主线是 ANE 在哪些条件下可以获得加速，以及量化粒度、图结构、算术参考和设备选择如何限制这种加速的实际应用。

四篇研究初稿均有完整中英文版本，以英文为默认入口，每篇标题下可以切换语言。第 01–03 篇的撰写没有新增设备实验；第 04 篇基于导入的 G2 夜间运行。

系列与配套文档已加入可缩放 SVG 图。图内使用英文标签以便复用，中文文章保留中文图注和替代文字；源数据、逐点数值、图示范围和生成方法汇总于[图表目录](../../docs/FIGURES.md)。

## 哪些结论已经有证据

| 结论 | 可定位的证据 | 当前边界 |
|---|---|---|
| 合成宽 K 量化链在当前路径上可重复加速 | [新吞吐记录](../../results/fresh/throughput.json)：`runs[].measured_records`、`admission`、`numerical` | T ops/s 按源图工作量计算；不证明物理 INT8、质量等价或完整 LLM 收益 |
| 同权重两层宽 K 路径的速度约为 K32 分解的四倍 | [新拆分记录](../../results/fresh/split.json)：三组独立进程的配对 p50 | 分解、归约和舍入边界一起变化；内部单一主因未隔离 |
| 保存后的权重正确、输出正确与 ANE 执行是独立检查 | [新 smoke](../../results/fresh/smoke.json)：`asset_audit`、`numerical`、`placement` | Core AI 无逐算子执行位置证明；不同框架的表示也不同 |
| 某些长链偏差可被明确的舍入参考解释 | [历史算术摘录](../../results/historical/arithmetic-reference-evidence.json)与新吞吐中的 `RNE-not-gate` | 更改解释没有更改设备输出；新参考需要新的冻结输入确认 |
| 精确网格仍可暴露 scale/表达相关错算 | 新 smoke 中 `coreai-qdq-*` 与 `coreai-group-*` | 错误模型预测成立，不等于已证明内部编译器实现；当前新测仅 0.4.1 |
| 候选算术模型在两个真实模型的最终 Q8 输出上只留下少量残差 | [交叉模型记录](../../results/historical/cross-model-validation.json)与[点积定位](../../results/historical/dot-localization.json) | 最终 Q8 有 13 处残差，QDQ 前更多；机制仍是假说 |
| 原生 W4A16 组件约为 GPU 速度的四分之一 | [G2 证据包](../../results/historical/g2-w4a16-night/)：七档、每侧三个宿主 | 单机、第一层 MLP；固定 tile 流水线，不代表硬件上限 |
| 原生宿主没有出现 Python 路径的每调用内存增长 | G2 `p0.json` 的自然检查点 | 有限运行；无限期常驻未测 |
| 相同负载下两侧风扇都在怠速，温度读数相差几度 | G2 同到达率六组配对 | 六分钟窗口、未达平衡；GPU 在 4.9–23.7 请求/s 之间未测 |
| 矩阵前台在 ANE 同跑时尾延迟代价更小 | G2 十八个共存时隙 | 仅一组热起始匹配；动态屏保未控制；独占基线本身有偏移 |

完整数字表由 [scripts/summarize.py](../../scripts/summarize.py) 从随仓库逐次计时记录生成，见 [MEASUREMENTS.md](../../docs/MEASUREMENTS.md)。历史记录标记为 `historical_import`，新套件记录标记为 `fresh_run`。文章中为了叙述使用的舍入值与来源字段一起引用，数值以来源字段为准。

## 文档职责与更新方式

`articles/` 负责解释实验动机、设计、结果和推断；[SCOPE.md](../../docs/SCOPE.md)集中声明所有边界，[METHODS.md](../../docs/METHODS.md)定义测量方法，[REPRODUCING.md](../../docs/REPRODUCING.md)说明环境与命令，[PROVENANCE.md](../../docs/PROVENANCE.md)记录来源，[RESEARCH.md](../../docs/RESEARCH.md)列出仍然开放的问题。

修改论点时，同步中英文的证据、限定和数字登记，先核对对应记录和代码状态。新工具链修复错误，应增加新观察并说明变化；历史失败仍然保留。更换输入、参考、门槛或图结构需要明确新的实验问题，并生成新的结果目录；历史记录不变。

若后续发展为论文，尚需独立设备复现、更强的单变量因果消融和更广分布验证。G2 已有组件热行为与 GPU 共存观察，但动态屏保未控制，共存组中仅一组热起始匹配；能耗、完整 LLM 质量/性能与跨设备外推仍未建立。[后续研究](../../docs/RESEARCH.md)
